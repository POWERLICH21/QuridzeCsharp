NECROPOLIS CASINO DUEL - HOW TO HOST A GAME FROM YOUR PC
=========================================================

Your PC runs a small game server. You and your opponent each open the game
in a browser. The server deals the cards and keeps each player's hidden
cards secret, so nobody can peek at the other army.


1. ONE-TIME SETUP
-----------------
Install Node.js (the free "LTS" version) from https://nodejs.org
Nothing else is needed; the server uses no extra packages.


2. START THE SERVER
-------------------
First unzip the download: right-click necropolis-casino-duel.zip and choose
"Extract All" (Mac: double-click the zip). Use the files in the unzipped
folder; double-clicking them inside the zip doesn't work.

Windows:  double-click  start-server.bat
          (if a blue "Windows protected your PC" box appears, click
          "More info" and then "Run anyway")
macOS:    double-click  start-server.command
          (first time: right-click it > Open, because it was downloaded)
Linux, or any system from a terminal in this folder:
          node server.js

A window opens and shows lines like:

    On this PC:            http://localhost:8080
    On your Wi-Fi/network: http://192.168.1.23:8080

If Windows asks whether Node.js may use the network, click "Allow"
(private networks are enough).

Your browser opens the game by itself. Keep that black window open while
you play. Close it (or press Ctrl+C) to stop.

Don't double-click client.html or server.js: they only work through
start-server.bat / start-server.command.


3. PLAY
-------
You:            the game is already open (or open  http://localhost:8080 ).
Your opponent:  see the options below.
Both of you type a name and press "Join the Table".


   A) Same Wi-Fi / home network (easiest)
      Send your opponent the "On your Wi-Fi/network" address from the
      server window, e.g. http://192.168.1.23:8080

   B) Over the internet, with a tunnel (nothing to download)
      Windows 10/11 and macOS already include "ssh", which can open a
      free tunnel at localhost.run. While the game server is running,
      open a second window (Windows: press the Windows key, type cmd,
      press Enter; Mac: open Terminal) and type:
          ssh -R 80:localhost:8080 nokey@localhost.run
      The first time it asks "Are you sure you want to continue
      connecting?": type  yes  and press Enter. It then prints an
      address ending in .lhr.life, like https://abc123def.lhr.life.
      Send that to your opponent. Keep this window open too; close it
      when you're done. The address changes every time, so send the new
      one each time you play.

      If that site is busy, the same idea works with Pinggy (free
      tunnels last 60 minutes):
          ssh -p 443 -R0:localhost:8080 free.pinggy.io
      and send the https:// address it prints.

      ngrok works as well. Windows Defender often blocks the ngrok
      download as a false alarm; installing it with winget avoids that:
          winget install ngrok.ngrok
      then  ngrok config add-authtoken YOUR-TOKEN  (from your ngrok
      dashboard) and  ngrok http 8080 . On the ngrok website the
      "Endpoints" page stays empty until ngrok runs on your PC.

   C) Over the internet, with your router
      In your router's settings, forward TCP port 8080 to this PC, then
      send your opponent  http://YOUR-PUBLIC-IP:8080  (find your public
      IP by searching "what is my IP"). Only open the port while you
      play, and close it afterwards.


IF IT DOESN'T WORK
------------------
- The black window says "server.js is not next to this file":
  the zip isn't unzipped yet. See step 2.
- It says "Node.js was not found": install Node.js LTS, restart the PC,
  and try again.
- It says "Port 8080 is already in use": the server is already running in
  another window. Use that one, or close it and start again.
- The page says "This file can't be opened directly": you opened
  client.html. Close it and double-click start-server.bat instead.
- "ssh" is not recognized: Windows Settings > System > Optional features
  > Add a feature > "OpenSSH Client", then open a new cmd window.
- Your opponent's page doesn't load on the same Wi-Fi: on Windows, allow
  Node.js through the firewall (Windows Security > Firewall > "Allow an
  app through firewall" > tick Node.js), or use option B instead.


GOOD TO KNOW
------------
- Two players per table. A third visitor sees "The table is full".
- Reloading the page keeps your seat. If a player is gone for more than a
  minute, someone new can take their seat (a new game starts).
- Each player's gold is saved in their own browser, under their name.
- Restarting the server clears the table; just join again.
- To use a different port:  set PORT=9000 && node server.js  (Windows)
                            PORT=9000 node server.js          (macOS/Linux)
- This is play money only. Players control their own gold in their own
  browser, so don't use it for real-money bets.
